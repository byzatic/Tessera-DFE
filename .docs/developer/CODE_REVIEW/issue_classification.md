P0 — критический: система полностью недоступна, потеря данных, серьёзная уязвимость. Требует немедленного исправления.
P1 — высокий: нарушается ключевая функциональность, возможна тихая некорректная работа, надёжного обходного пути нет.
P2 — средний: существенная проблема, но проявляется при определённых условиях или существует обходной путь.
P3 — низкий: небольшой дефект, ограниченное влияние.
